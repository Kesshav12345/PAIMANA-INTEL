# CONCEPTUAL MODEL

## Entities
1. **Project**: The core infrastructure initiative.
2. **Observation**: A monthly snapshot of a project's state.
3. **Organization**: Ministries, Departments, and Agencies.
4. **Sector**: The domain of infrastructure (e.g., Transport, Energy).
5. **Geography**: State/Region where the project is implemented.
6. **Economic Index**: Macro indicators mapping to sectors over time.
