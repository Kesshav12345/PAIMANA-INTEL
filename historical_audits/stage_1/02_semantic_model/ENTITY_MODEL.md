# ENTITY MODEL

## 1. Project
- **Grain**: One row = One unique infrastructure project (represented by Project ID).
- **Attributes**: Project Name, Project ID, Ministry, Department, Implementing Agency, Sector, Geography/State.

## 2. Project Observation
- **Grain**: One row = One project at a specific point in time (Reporting Month).
- **Attributes**: Original Cost, Revised Cost, Cumulative Expenditure, Physical Progress %, Reporting Period, Risk Status.

## 3. Organization
- **Grain**: One row = One authority.
- **Attributes**: Ministry Name, Department Name, Implementing Agency Name.

## 4. Sector
- **Grain**: One row = One infrastructure sector.
- **Attributes**: Sector Name, Benchmark averages.
