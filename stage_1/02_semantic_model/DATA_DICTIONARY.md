# DATA DICTIONARY

- **PROJECT ID**: Unique identifier for the project. Type: String/Integer.
- **PROJECT NAME**: Official name of the project. Type: String.
- **ORIGINAL COST**: The initially approved cost of the project in ₹ Crores. Type: Numeric (Float).
- **REVISED COST**: The updated/revised cost of the project in ₹ Crores. Type: Numeric (Float).
- **EXPENDITURE**: The cumulative expenditure incurred up to the reporting date in ₹ Crores. Type: Numeric (Float).
- **PHYSICAL PROGRESS (%)**: The physical completion percentage of the project. Type: Numeric (0-100).
